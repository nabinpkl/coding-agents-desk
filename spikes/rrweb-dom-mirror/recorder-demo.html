Crisp text at tiny bandwidth

This page is recording its own DOM with rrweb and streaming the mutation log to the relay. Open the viewer in another tab — everything here is re-rendered there by the viewer's own browser, so the text stays vector-sharp no matter the network.

Why this is cheap

A pixel encoder ships a grid of colors every frame. rrweb ships structure: one full snapshot, then tiny deltas that reference node ids. A ticking clock or an appended log line is a few dozen bytes, not a re-encoded tile. Watch the KB/s in the relay console while nothing moves — it drops toward zero.

// the entire recorder, minus batching plumbing
rrweb.record({
  emit(event) { batch.push(event); },   // DOM + input + scroll deltas
  checkoutEveryNms: 5000,        // periodic full snapshot for late joiners
});
