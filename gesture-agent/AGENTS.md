
# Agent instructions

Load these first before editing code if not already loaded into your context.

**At session start, and again after any context compaction, read these files if they are not already in context. Do not skip. Do not assume they are loaded.**
These files do not live in this repo: they are in the author's own rules library, a private checkout beside this one. If you do not have it, follow the repository root `AGENTS.md` and say that these were not available, instead of inventing rules.

1. `taste/library/universal-AGENTS.md` cross-cutting worker rules. Authoritative for voice, scope discipline, output format, coding rules, and how to write for other agents.
2. `taste/library/iteration/TASKS-MD-Guidelines.md` the shape of `TASKS.md` for any iteration that opens.
3. `taste/library/languages/python.md` Python conventions. Authoritative when writing or reviewing Python in this repo.
